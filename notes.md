<h3>VSCode</h3>
This is a modern code editor for writing html documents. It also adds another convenience layer for syntax highlighting and automatic code completion. In addition to these basics, *vscode* also has some extensions that adds a layer of functionality for example you can open the html document using the Live Server extension and you will be able to see what really happens between a when a request to the server is made via the browser.

<h3>Node.Js</h3>
Node.Js provides a JavaScript runtime outside the browser. In other words, Node.Js allows us to run JavaScript ousde the browser.

<h3>Git</h3>
Git is the software we store on our local computer so that we can track the progress of our code development efforts.

<h3>Terminal</h3>
The terminal also called the command line allows us to control our computer using text commands. Using the terminal aids in speed and efficiency, automation, and remote access to servers.
