### The Request Journey
1. The request journey begins in the browser where a user types in the url(uniform resource locator) and presses enter. 
2. The browser sends the url to a DNS server which contains a mapping of domain names and IP addresses of the host servers
3. Using the returned IP addresses the browser uses http protocol to send the request to the server.
5. The server returns the response to the server as an html document. The browser unpacks the html for the user to view

### How is the Internet different from the World Wide Web?
The internet consist of a global connection of computers and devices whilst the World Wide Web refers to a collection resources/information (documents and multimedia content) that are found on very powerful computers known as servers. Servers are accessed via the internet.
